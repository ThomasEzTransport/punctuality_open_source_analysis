This python repository aims to handle punctuality big data from open sources initiative. 
(For Chuuchuu data use the dedicated tool)

As it stands (October 2026) the codes target two sources

**- Rijden de treinen**
  Open source initiative in the Netherlands (source already used for the rail ranking in 2024)
  https://www.rijdendetreinen.nl/open-data
  
**- Open ritardi**
  Open source initiative in Italy
  https://www.openritardi.org/en/statistics.html  /  https://trainstats.altervista.org/


The raw dataset are stored in the google drive repository
https://drive.google.com/drive/folders/1A9ZRchVYW2egtOszCSS1_y8L7ncHAjLs
